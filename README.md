# Coil

Coil is a neon grid serpent game for the browser. Steer through an enclosed grid, collect pellets to grow, and collect the next one quickly to raise your score multiplier. The combo window runs out after 3.5 seconds of play.

## Run

```sh
npm ci
npm run dev
```

Open the address Vite prints. For a static site, run `npm run build` and serve the generated `dist/` directory. The build bundles the committed art and audio files; it does not need asset generation tools.

## Controls

| Action | Keys |
| --- | --- |
| Steer | Arrow keys or WASD |
| Select menu item | Enter or Space |
| Pause or resume | Escape or P |
| Mute | M |
| Debug overlay | Backtick |

Menus also respond to pointer and touch. Touch controls appear on touch input.
